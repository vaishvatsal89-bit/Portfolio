TaskCampus

Live at taskcampus.in

A campus task marketplace. Students post small jobs, other students pick them up, money moves through Razorpay, and completion is verified with a one-time code before anyone gets paid. I took it from a localStorage prototype to a deployed product in four phases.

How it got built

Four phases, in order. Each one replaced something that had stopped being good enough.

Plain HTML, CSS and JavaScript

A working prototype backed by localStorage. Enough to prove the flow made sense before writing anything serious.

Rebuilt in React and Vite

Proper component architecture and React Router. The prototype's logic survived; almost none of its code did.

Supabase for auth and data

Postgres with row level security, real authentication, and live task updates over realtime subscriptions instead of polling.

Payments and verification

Razorpay integration, UPI wallet withdrawals, and OTP-based task verification so a task has to actually be finished before money moves.

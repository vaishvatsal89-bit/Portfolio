## What's on it

- An honest skills breakdown (solid / working / learning), not inflated progress bars.

## Stack

Plain HTML, CSS, and vanilla JavaScript. Canvas for the hero background effect. No React, no build tools — the whole site is one file so it deploys anywhere in seconds.

## Running locally

Just open `index.html` in a browser. There's nothing to install.

## Deploying

Push this repo to GitHub, then import it on [Vercel](https://vercel.com) — no framework preset or build command needed, it serves `index.html` as-is.
